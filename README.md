**Bouncy Cartoon** -

An interactive bouncing cartoon character made with Processing.

The cartoon moves around the screen, bounces off the edges, and changes colours when you use the keyboard and mouse.

**Features**

1.Bouncing movement: the cartoon starts in a random direction and bounces off the edges of the window

2.Changing eye colour: the eyes turn brown in the lower half of the screen and black in the upper half

3.Pink background: press T to change the background from white to pink

4.Mouth colour: click the mouse to turn the mouth white

5.Drag to move: click and drag to move the cartoon anywhere

**Controls**

1.Press T or t	Background turns pink

2.Click the mouse	Mouth turns white

3.Drag the mouse	Cartoon follows your cursor

**How to run it**

Download and install Processing from processing.org/download.

**Download this repository:**

Click the green Code button on this page, then Download ZIP, and unzip it, or
Clone it with Git:
git clone https://github.com/YOUR-USERNAME/processing-bouncy-cartoon.git

Make sure the file bouncycartoon.pde is inside a folder named bouncycartoon. Processing needs the folder and the file to have the same name.
Open bouncycartoon.pde in Processing.
Click the Run ▶ button at the top left.

**Built with** - Processing (Java mode)

3.Making objects bounce with if conditions

4.Handling user input with keyPressed(), mousePressed() and mouseDragged()
